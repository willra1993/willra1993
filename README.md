# William Araujo

Data Scientist e profissional de Data Analytics na MAPFRE, em São Paulo. Desenvolvo projetos que conectam preparação de dados, automação, machine learning e visualização para transformar dados em análises confiáveis e decisões mais claras.

## Áreas de atuação

- construção de pipelines de dados reproduzíveis e automatizados;
- análise exploratória e modelagem com Python e scikit-learn;
- dashboards e storytelling de dados com Power BI;
- desenvolvimento de ferramentas com validação, testes e documentação.

## Projetos em destaque

### [Pipeline de dados do Galaxy Watch](https://github.com/willra1993/Pipeline_de_Dados_Galaxy_Watch)

Pipeline ponta a ponta que integra Samsung Health, Google Drive, Apps Script, Google Sheets e Power BI. O projeto aplica processamento incremental, idempotência, bloqueio de concorrência, observabilidade e cuidados com privacidade.

[Ver dashboard no Power BI](https://app.powerbi.com/view?r=eyJrIjoiYTYzZmUyMzQtNmMwYy00NjM5LWFhNDEtZTVkYmYzMTRjNGIyIiwidCI6IjExNjBiYzYwLTA4ZTgtNDNhMi1iMTYxLWQ4MDlhZjJlNGJlMyJ9)

### [Separador de públicos A/B](https://github.com/willra1993/separador-publicos-ab)

Aplicativo desktop em Python para criar grupos comparáveis de forma reprodutível. Inclui estratificação, pareamento por vizinhos mais próximos, suporte a diferentes formatos de entrada e exportação para Excel.

### [Análise exploratória e regressão linear](https://github.com/willra1993/Analise_Exploratoria_e_Regressao_Linear)

Estudo de preços de imóveis da Califórnia com engenharia de atributos, pipeline sem vazamento de dados e avaliação fora da amostra. O modelo alcançou RMSE de US$ 68.453 e R² de 0,642 no conjunto de teste.

### [Data Visualization com Power BI](https://github.com/willra1993/Data_Visualization_Power_BI)

Portfólio de dashboards que explora modelagem, Power Query, mapas e storytelling visual em análises sobre o Oscar e a população brasileira.
